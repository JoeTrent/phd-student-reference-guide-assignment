# Requirements

## User Stories

1. Collection Methods: 
    As a PHD student, I want to know what the avaliable collection methods are, To make sure to pick the most suitable one. 

2. Data Sources: 
    As PHD student, I want to know where I can collect data from, to make sure I select the correct and reliable data that is the most suitable for my needs.

3. As a PHD student, I want to know what analysis methods I can use, to make sure to select the best method for my work.

4. As a PHD student, I want to know where I can publish my research, to make sure I publish my work at the most fitting venue. 

5. As a researcher, I want to know which analysis method to use, to make sure I'm using the best one for my work.
