Data Sources

This page is blank and being worked on

  1. GitHub

    GitHub is a cloud-based web platform that developers use to store, manage, and collaborate on code.

    Data source provides: repositories, commits, pull requests, issues, stars

  2. Stack Overflow

    Stack Overflow is a massive, free question-and-answer platform dedicated exclusively to computer programming and software development.

    Data source provides: questions, answers, tags, user reputation

  3. JIRA

    JIRA is a proprietary project management and issue-tracking software product developed by Atlassian.

    Data source provides: issue tracking, sprint data, bug reports

  4. App Stores

    An app store is an online digital marketplace where users can browse, purchase, download, and update software applications for their devices.

    Data source provides: Google Play and Apple App Store reviews, ratings, downloads

  5. Travis CI / Jenkins

    Travis CI and Jenkins are both Continuous Integration and Continuous Delivery (CI/CD) tools used by software developers to automate the process of building, testing, and deploying code changes.

    Data source provides: build logs, test results, deployment data

  6. Mailing Lists

    Mailing Lists is where devs talk and communitcate about software development and developed research in the tech field

    Data source provides: developer discussions, archives

  7. npm Registry

    An npm Registry is a centralized online database that stores, version-controls, and manages JavaScript code packages.

    Data source provides: package dependencies, downloads, versions
